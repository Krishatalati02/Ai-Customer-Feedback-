# 💬 AI Customer Feedback Analysis Agent

## 📖 Overview

The **AI Customer Feedback Analysis Agent** is an intelligent workflow automation project built using **n8n**, **Google Gemini**, and **Discord**. The system automatically collects customer feedback from Discord channels, analyzes the sentiment and intent using AI, categorizes feedback into meaningful groups, and generates actionable insights to help businesses improve their products and services.

By combining workflow automation with Large Language Models (LLMs), this project transforms raw customer messages into structured insights, reducing manual analysis and enabling faster decision-making.

---

## ✨ Features

- 💬 Automatically collects customer feedback from Discord.
- 🤖 Analyzes feedback using Google Gemini AI.
- 😊 Performs AI-powered sentiment analysis.
- 🏷️ Categorizes feedback into relevant topics.
- 📊 Identifies trends and recurring customer concerns.
- 📝 Generates concise summaries of customer opinions.
- ⚡ Fully automated workflow using n8n.
- 🔗 Easily customizable for different communities and businesses.

---

## 🚀 Workflow

1. Monitor customer feedback from Discord channels.
2. Extract message content automatically.
3. Send feedback to Google Gemini for AI analysis.
4. Determine sentiment (Positive, Neutral, or Negative).
5. Categorize feedback into relevant topics.
6. Generate concise summaries and actionable insights.
7. Store or forward the analyzed results for further use.
